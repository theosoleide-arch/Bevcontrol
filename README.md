# BevControl

A premium SaaS beverage management and control application built with React, Vite, and Recharts.

## Features

- Beverage inventory management
- Sales tracking and analytics
- Revenue reporting
- Interactive charts and dashboards

## Tech Stack

- React 18
- TypeScript
- Vite
- Recharts

## Development

```bash
npm install
npm run dev
```

## Deploy

Deployed via Vercel. Push to main branch to trigger automatic deployment.
